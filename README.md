# GrooveSpace - Desarrollo y avances

Este repositorio contiene el trabajo realizado en el desarrollo de GrooveSpace, principalmente en las áreas de backend, integración con frontend y panel administrativo.

## Trabajo realizado

### Backend
- Desarrollo y organización de la API utilizando Node.js y Express.
- Implementación de las rutas de usuarios, reservas y salas.
- Implementación del registro e inicio de sesión.
- Incorporación de autenticación mediante JWT.
- Protección de rutas según el rol del usuario.
- Validación de reservas y horarios.
- Control de reservas superpuestas para una misma sala.
- Implementación de cancelación de reservas.
- Almacenamiento de información mediante archivos JSON.

### Frontend e integración
- Integración de las funcionalidades del frontend con el backend.
- Ajustes en el inicio y cierre de sesión.
- Gestión de sesiones de usuarios y administradores.
- Adaptación de las redirecciones según el rol.

### Panel administrativo
- Organización del panel en cuatro secciones: Dashboard, Reservas, Salas y Configuración.
- Incorporación del logo de GrooveSpace.
- Mejoras visuales y de navegación.
- Desarrollo de una agenda de reservas con distribución por salas y horarios.
- Ajustes en la visualización de las reservas.

## Estructura de trabajo

- `backend/`: desarrollo de la API y sus funcionalidades.
- `frontend/`: interfaz web e integración con el servidor.
